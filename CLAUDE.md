# Oosai: Tamil speech-to-speech voice agent

Read `README.md` before doing any work. It holds the goal, decisions, ruled-out models,
the recommended pipeline, Tamil-specific pitfalls, the phased plan and environment lessons.

- At the start of a session, restate the goal and the next step from README §12 before acting.
- Keep README.md current: update the "Updated" date, §12 "Next step", and any decision or
  ruled-out entry at each milestone, instead of starting new notes files.
- Only licenses that allow commercial use (see README §4). Voice cloning only with the speaker's
  written consent.
- Bind any local server to 127.0.0.1, never 0.0.0.0.
